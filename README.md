# P. Siva Shankar — Portfolio

A responsive portfolio website created from the information in the provided resume.

## Files
- `index.html` — portfolio structure and resume-based content
- `style.css` — responsive futuristic visual design
- `script.js` — mobile navigation, reveal animations and dynamic year

## Run locally
Open `index.html` in a browser.

For a local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy
This is a static website, so it can be deployed directly to GitHub Pages, Netlify, Vercel, or Cloudflare Pages.

## Resume source
The content is based on the supplied P. Siva Shankar resume, including the summary, education, skills, Cisco certificate, BizNexus project, and CyberShield project.
